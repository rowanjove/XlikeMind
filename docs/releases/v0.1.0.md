# XlikeMind v0.1.0

首个 Chrome Manifest V3 版本，本地优先的 X 点赞与收藏归档工具。

## 功能

- 手动采集、扫描上限、暂停/继续和中断恢复，跨批次去重。
- 正文、多图顺序与本地图片保存，缺失内容与失败原因明确标记。
- 多份本地文库隔离，搜索、筛选、人工标题/标签/笔记及阅读状态。
- 主题汇总、增量简报，可选 OpenAI-compatible AI 整理和离线 Mock。
- Markdown ZIP 图文导出、本地目录归档、独立 index.html 离线阅读。
- 弹窗直接同步、完成后操作设置、诊断报告和采集质量统计。

## 安装

下载 `XlikeMind-v0.1.0-chrome.zip`，解压后在 `chrome://extensions` 开启开发者模式，加载 **extension** 文件夹。详见包内 INSTALL.md。

附件：扩展ZIP、SHA256SUMS.txt、THIRD_PARTY_NOTICES.txt。

## 验收与范围

- 自动化覆盖采集、保存、检索、恢复、图文ZIP解压和安装产物检查。
- X 访问限制、页面结构变化和图片失效仍可能导致部分结果。默认本地运行，不修改 X 账户，不绕过限流。
- 仅 Chrome 扩展，不开发桌面 EXE、Tauri 或 Electron。

## 升级与数据

已有开发版请保留原加载目录更新并重新加载，不先卸载。不同扩展ID不会自动共享 IndexedDB。建议升级前导出备份。
