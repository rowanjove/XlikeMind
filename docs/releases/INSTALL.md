# XlikeMind v0.1.0 安装

1. 解压 `XlikeMind-v0.1.0-chrome.zip` 到长期保留的目录。
2. 打开 Chrome 的 `chrome://extensions`，开启「开发者模式」。
3. 选择「加载已解压的扩展程序」，选中解压后的 **extension** 文件夹（该目录下有 manifest.json）。
4. 固定工具栏图标，打开扩展。在设置中选择本地文库保存目录。
5. 在已登录的 X 点赞或收藏页刷新一次，再从扩展手动开始同步。单次默认100条，可自行调小。

## 更新已有开发版

优先备份导出。保留原扩展及其加载目录，将新包 `extension` 内的文件更新到原目录，再在扩展管理页点击「重新加载」。不要先卸载旧扩展。不同扩展ID的数据不会自动合并；本版本不新增或更换 manifest key。

## 本地数据与权限

帖子与图片默认保存在扩展的 IndexedDB，可导出带图片的 Markdown ZIP，也可绑定本地目录。设置中的「检查授权与入口」可检查现有 index.html，不重写整个归档。

AI 为可选功能，默认不发送图片，使用前明确确认目标接口与发送范围。不配置 AI 也能浏览、编辑、搜索和导出原文。

X 可能限制历史内容访问。达到扫描上限、登录失效或限流会明确提示，不代表全部历史已采集。视频只保留链接或可获得的封面，不归档视频正文。
